# 比较搜索表现

按 Google 的太平洋时间写明起止日期（含两端）、搜索类型、站点、过滤器、聚合和数据状态。需要小时数据时选择 hour 和 hourly_all，注明未定稿的起始时间。比较相同长度、完整程度相同的窗口。

1. 先分别查询两期的无维度汇总。报告点击差和相对变化，基数为零时相对变化无法计算。CTR 用总点击除以总展示；平均排名使用同口径的上游值。
2. 按问题选择 page、query、device 或 country 等维度。以两期热门行的并集为候选。某页只出现在一期时，在剩余预算内以 page equals 精确 URL 查询缺失的一期。仍无数据即保留缺失。
3. 分页用 rowLimit（每次最多 25,000）及 startRow，短页或空页结束。Google 优先返回热门行，并可能隐藏匿名查询。热门行相加不足以推断全站总量。输出两期行数、覆盖和筛选条件。
4. 区分实际变化和原因假设。例如汇总 1,000→800、页面 A 300→180，可以报告全站少 200 次、A 少 120 次。页面 B 仅见于前一期明细，不能据此归零。标题、竞争或算法原因需要其他证据。
